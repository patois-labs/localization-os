# Localization OS 1.3.1

Release 1.3.1 is a dependency security update on top of 1.3.0. Nothing else changes: no migration, no settings,
no behaviour change.

## Security and dependency updates

- `opentelemetry-api` moves from 1.45.1 to 1.45.2 (CVE-2026-126360). It is pinned in `requirements.lock` and in the
  Vendor Studio image's lock; both now carry the 1.45.2 hashes from PyPI.

## Upgrade notes

1. Refresh the dependencies: `pip install -r requirements.lock`. This installs `opentelemetry-api` 1.45.2; no other
   package moves.
2. There is no migration. A backup before upgrading is still good practice (`loc-tms db backup-full`).
3. In the container, rebuild the image so the new pin lands.

## Known limitations

- Unchanged from 1.3.0. An image scan of the Dockerfile still flags CVE-2026-78661 in the `golang.org/x/net` copy
  inside the tailscale binaries (v1.104.7 is the newest stable release); it applies only when Tailscale is turned on
  with an auth key.
