# Localization OS 1.0.0

The first open source release. Localization OS is now licensed under the Apache License 2.0, with documentation
under CC BY 4.0. Contributions are welcome under the Developer Certificate of Origin (see CONTRIBUTING.md).

## Highlights

- **A complete self-hosted TMS.** Configurable translation workflows with quality checks, fix-and-recheck loops and
  human review steps; translation memory with locks; glossaries; style guides; content types; a post-editing editor;
  reports and a dashboard.
- **Content in and out.** More than 80 file formats returned in the same format and layout. Three project types:
  documents, string keys (with a delta API for CI) and projects connected to a source system.
- **Connectors.** 28 connectors, including Airtable, Jira, Strapi, Contentful, HubSpot, WordPress, Shopify, Zendesk,
  Confluence, GitHub, GitLab, SharePoint and Google Docs. Translations go back as each system's own language version.
- **Collaboration.** Queries and comments on segments, documents, keys and projects; a reviewer worklist; external
  vendors with a signed dispatch and return.
- **Security and administration.** SSO (OIDC, SAML, LDAP / Active Directory), SCIM provisioning, MFA, a
  tamper-evident audit chain, the LLM Ledger, GDPR export and erasure, PII redaction including name detection,
  encryption at rest, and a durable database job queue.
- **Built for agents.** A full REST API, a headless CLI with more than 480 commands, and an MCP server with 72 tools.
- **Engines.** Cloud engines (Claude, Gemini, OpenAI, DeepL, Google, Microsoft, Amazon and others), local
  self-hosted models, failover and a spend cap. The offline mock engine is the default, so a new install works with
  no keys.

## Getting started

```bash
git clone https://github.com/patois-labs/localization-os.git
cd localization-os
python3 scripts/bootstrap.py      # Windows: python scripts\bootstrap.py
```

Then start it with `run.py` (see README.md) and open <http://127.0.0.1:8000>.

## Open core

The core in this repository is complete and free. Patois Labs offers paid add-ons for specialist needs: Advanced
Workflows (an agent-based tier with web verification), the Evaluations Lab, semantic translation memory, LLMemory,
Databricks export, and the OpenTelemetry, Prometheus and S3 adapters. Their database tables are part of the core
schema and stay empty without the add-on. What stays free forever is written in STEWARDSHIP.md.

## Notes for existing installs

- Requires Python 3.10 or newer.
- Projects created through the API or CLI without an engine now use the install's configured default engine.
- Strict TBX validation needs the official TBX-Basic schema files, which are no longer bundled: fetch them with
  `python scripts/fetch_tbx_schemas.py`. Normal TBX import and export work without them.
- A database upgraded from an earlier full edition keeps any add-on data; deleting a project or document cleans up
  leftover add-on rows, and the app logs a warning at startup when add-on tables hold data the core cannot manage.
