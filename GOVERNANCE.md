# Governance

Localization OS is maintained by **Patois Labs, LLC**, which created it and sets its direction.

- **Decisions.** The maintainers decide what is merged and what the roadmap holds. Significant design decisions are
  recorded as architecture decision records in [docs/decisions/](docs/decisions/INDEX.md).
- **Contributions.** Anyone may propose changes through issues and pull requests (see
  [CONTRIBUTING.md](CONTRIBUTING.md)). Every commit carries a DCO sign-off; there is no contributor license agreement.
- **Open core.** The core in this repository is Apache 2.0. Patois Labs builds some paid add-ons in a separate
  repository. What stays free, and the rule that nothing free ever becomes paid, are written in
  [STEWARDSHIP.md](STEWARDSHIP.md).
- **Security.** Vulnerabilities are handled privately as described in [SECURITY.md](SECURITY.md).
- **Conduct.** Everyone follows the [code of conduct](CODE_OF_CONDUCT.md).
- **Names.** The project's names and logos are covered by [TRADEMARKS.md](TRADEMARKS.md).

As the community grows, this page will describe how contributors can become maintainers.
