# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue, pull request or discussion.

- **Preferred:** GitHub private vulnerability reporting. Go to the repository's **Security** tab and choose
  **Report a vulnerability**.
- **Email:** support@patoislabs.com

Include what you found, the version or commit, steps to reproduce, and the impact you expect. A proof of concept
helps. Please give us a reasonable chance to fix the problem before you disclose it.

## What to expect

- We acknowledge your report within 3 business days.
- We confirm the problem and tell you our plan within 10 business days.
- We fix confirmed issues as quickly as their severity requires, publish a security advisory, and credit you unless
  you ask us not to.

## Supported versions

Security fixes go into the latest release. Patois Labs offers longer support windows to paying support customers.

## Scope

In scope: the code in this repository, including the web app, API, CLI, MCP server and deployment kits. Out of scope:
third-party services you connect to it, and installs you have modified. Testing against an install you do not own,
including any Patois Labs hosted service, requires written permission first.

Security fixes are always part of the free open source core (see [STEWARDSHIP.md](STEWARDSHIP.md)).
