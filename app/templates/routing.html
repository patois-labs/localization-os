A rule matches on extension and department and sets a project and/or provider. Subject matching and workflow / language-set targeting are reserved for v2 and are not consulted at run time yet, so they cannot be set here.

Rules take effect on two API paths only: a rule's project places an upload on POST /api/documents (only when the caller names no project), and a rule's provider override applies on POST /api/documents/{id}/translate (via API, MCP or --remote CLI) - the only place a provider target has effect. Web-UI uploads and in-process CLI uploads consult no rules.

Project budgets

Cap the money a project may spend per month - both AI model spend (machine translation + workflow runs) and settled vendor human spend, attributed to the project. No budget or a limit of $0 = unlimited. At 100% of the cap, new machine-translate submissions and new vendor dispatches for that project are refused until next month; human review and editing are never blocked. Committed-but-unpaid vendor work is shown as a marker on the meter but is not enforced against.
