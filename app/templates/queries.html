About query notifications

Query notifications are email only. There is no in-app notification centre, no digest, no Slack or webhook target, and no per-user notification preferences. If SMTP is not configured, no notification is sent and nothing is logged (mailer.configured() returns False and the send is a silent no-op) - the only in-app signal that a query is waiting for you is the My work page and the query lists. An unassigned query notifies nobody, by design.
