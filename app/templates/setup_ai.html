💳 Spend cap

A monthly ceiling on real AI spend. When this month's spend reaches the cap, new AI translations are blocked with a clear error until you raise or clear it - a safety brake against runaway cost. Set 0 to turn it off. The mock/offline engine, private-network local engines and a Jev-compatible local server are exempt. Hosted Jev quality judge calls count and stop at the cap, and a workflow's auto-fix loop that can cost money does not start (or stops between rounds) once it is reached. Prices are estimated from token usage per a built-in per-model table. Only an administrator can change the cap (the same rung as adding a cloud key or disarming the mock-egress guard); the local operator can also set it with config set spend_cap_usd. In multi-org mode only the host operator can change this install-wide cap; organization administrators cannot change it over web or API.

Ask and Draft allowance

Paid Ask and both Draft actions share a per-person allowance. Defaults are 6 calls per minute and 60 per UTC day. Set 0 for unlimited in that window. Failed calls and repair calls count. The host CLI has its own system bucket with the same limits, separate from web users even when sign-in is off. Only administrators can edit; in multi-org mode use the host CLI config settings.
